; Pico's face: the PICO-8 glyph design as a pixel table.
;
; Design: Zep (Lexaloffle Games), released under CC0 1.0
; (https://www.lexaloffle.com/pico-8.php?page=faq). This file carries only the
; design, one bitmap per character; scripts/build-font.py turns it into
; src/fonts/pico8.woff2. The bitmaps for printable ASCII were read out of
; jacobpierce's reproduction of the design. The entries after "Additions" are
; Pico's own, drawn in the same 3x5 cell for characters Korri's copy uses and
; PICO-8 has no glyph for.
;
; Format: "<hex codepoint> <name>", then five rows of "#" ink and "." paper,
; top row first, any width. Advance is width + 1. Lines starting ";" are notes.
; Uppercase A-Z are not listed: the builder maps them to the lowercase glyph,
; so copy looks the same whatever its case. PICO-8 draws button icons for some
; capitals; Pico draws its buttons as elements instead.
