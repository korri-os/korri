# Choose image variants and first-use readiness

Parent: [One Korri product across devices](../map.md)
Label: wayfinder:grilling
Type: grilling
Status: open
Blocked by: 05

## Question

Given measured size and plugin availability, should Korri offer only an opinionated image or both minimal and opinionated images, and what can each do before downloading anything?

Simon's preference is conditional, not a commitment to two images: offer only the opinionated image if the size difference is trivial. No numeric threshold has been selected. Present the actual measurements and their limits before asking for the choice.

Keep the intended product consistent across variants. Distinguish bundled plugin payloads from available product behavior, owner approval, supplied content, and network access. Define what a user must do before the first successful local play session and what happens when a required download is unavailable. Do not label an image offline-ready based only on package presence.

Resolve the variant and first-use promise with Simon. If measurements exclude required unfinished packages, obtain an explicit provisional decision or leave the ticket open; do not silently treat partial evidence as final.
